PROJECT 02 · MAJOR

Smart Security System for Farm Protection

Problem: Farmers lose crops to animals, birds, and fires nightly — with no automated, affordable protection system available.

PIR Sensor Arduino UNO Buzzer/Alert Fire Sensor Microcontroller
Outcome: A cost-effective embedded system detecting intrusions and fire, triggering alerts — protecting farms 24/7 without human supervision.
⟶ GitHub 5th Sem · 2024
PROJECT 03 · MINOR

Monostable Multivibrator using IC 555

Problem: Precise, adjustable pulse timing circuits are fundamental to embedded systems — understanding their design is critical to hardware development.

IC 555 RC Circuit Oscilloscope PCB Design
Outcome: Successfully designed and implemented a precision monostable circuit, demonstrating mastery of timer ICs and pulse-width control fundamentals.
⟶ GitHub 4th Sem · 2023
PROJECT 04 · IN PROGRESS

Human-in-the-Loop E-Bike Adaptive Control

Problem: Standard e-bikes apply fixed motor assistance regardless of rider fatigue, terrain, or physiological state, reducing efficiency and comfort.

MATLAB Machine Learning Torque Sensors ESP32 Adaptive Control
Outcome: An ML-driven adaptive torque/motor control research build personalizing pedal effort in real-time — basis of two published conference papers.
⟶ GitHub 🔄 In Progress
PROJECT 05 · IN PROGRESS
